# Security policy

## Report a vulnerability

Do not open a public issue or discussion for a vulnerability. This repository takes no issues.

Report it privately on GitHub:

1. Open the **Security** tab of this repository.
2. Select **Report a vulnerability**.
3. Tell us what you found, how to reproduce it, and the commit or image version you used.

Only the maintainers see the report. We reply in the same advisory.

## Supported versions

We fix vulnerabilities in the latest commit on `main` and in the latest image at
`public.ecr.aws/runfactorial/factorial`. Older images get no fixes.
